# Exploration ideas

Ideas are possible routes, not active commitments. Promote an idea when you can state a concrete question, smallest artifact, and observable outcome.

| Idea | First question | Smallest useful artifact |
| --- | --- | --- |
| Tiny browser | How does a document become positioned boxes? | A parser and block layout for a deliberately small HTML/CSS subset |
| Linux source reading | Where does a write cross into the kernel? | Annotated syscall trace and a pinned source walkthrough |
| GPU computing | When does parallelism lose to memory transfer? | CPU/GPU kernel with controlled workloads and transfer-inclusive measurements |
| Formal verification | Which invariant rules out a lost update? | A bounded state-space model and a counterexample to an incorrect rule |
| Cryptography | Why is nonce reuse dangerous? | A local known-input demonstration with an explicit threat model |
| Quantum computing | How do amplitudes differ from ordinary probabilities? | A two-qubit simulator with measurement and interference examples |
| Robotics | How does delayed sensing destabilize feedback? | A controllable discrete-time feedback simulation |
| Production architecture | Which dependency limits throughput or availability? | A bounded workload model with queues, failure assumptions, and observable bottlenecks |
