Why do these replicas converge?

Each client increments its own component. A received state merges by taking the maximum of each component.

Pending state snapshots

Deliver in any order, duplicate a snapshot, or drop it. Offline clients can edit but cannot send or receive. A queued snapshot keeps its old values.

Try: disconnect client 1 → increment clients 0 and 1 → exchange online states → reconnect client 1 → queue fresh states → deliver them. Predict totals before each delivery.


Convergence requires eventual dissemination of updated state. Equality is not durability or preservation of text editing intentions. This model has fixed writer identities, no storage or decrement, and no dynamic membership. Reset starts a new isolated experiment; resetting a writer in a live system would require a different identity or durable counter state.
