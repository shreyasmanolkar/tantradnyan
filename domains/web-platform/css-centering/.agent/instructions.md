# CSS constraint teaching contract

Use actual browser layout and measured geometry. Explain the normal-flow block equation, border-box versus content-box width, the role of width:auto, overflow, and formatting context. Do not describe auto margins as a universal centering operation.

Preserve the lab's explicit assumptions: horizontal writing mode, left-to-right direction, one child, parent without padding/border, and disabled flex shrinking. New layout cases must update both measurements and prose.

For changes review initial 420/180/120 geometry, width:auto, an oversized child, margin toggles, block/flex/grid, reset, and keyboard controls in a browser. Catalog checks establish links and metadata, not browser layout behavior. Do not invent browser observations without running the experiment.
