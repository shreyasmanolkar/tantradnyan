The parent has no padding or border. The child's reported width includes its padding and border because it uses box-sizing: border-box. The geometry shows signed gaps, which may differ from computed margins when a box overflows or alignment positions it.


Scope: one block child; horizontal writing mode; left-to-right direction. Flex and grid have their own sizing and alignment rules. This lab uses the browser itself, rather than a hand-written approximation of CSS.
