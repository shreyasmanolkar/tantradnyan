# Guides

Each guide lives in its own directory named with a short, lowercase topic slug. Use [`TEMPLATE.md`](TEMPLATE.md) as the starting point. The template is a thinking aid: adapt sections to the topic, and explain why a section does not apply when that omission could leave a gap for the reader.

Guides in progress may be labeled `draft`. Use `review` when the technical research and explanation are complete and need another reader. Use `ready` only after the substantive review questions in the template have been answered.
