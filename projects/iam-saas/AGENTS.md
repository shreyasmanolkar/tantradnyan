# Integration boundaries

Read the [IAM domain instructions](../../domains/identity-access-management/AGENTS.md) and [project README](README.md). This app is loopback-only and educational. Keep authentication, local principal resolution, tenant policy and provisioning effects explicit. Do not claim in-memory state is durable or JSON teaching endpoints are full OAuth conformance.

Run the stage-22 HTTP checks through the Node lab npm test command. Browser behavior needs the documented browser review. Database checks are separate; changing memory handlers does not automatically implement PostgreSQL persistence.
