# Templates

Copy only what the topic needs. Templates are writing and design prompts, not required empty folders.

- [Topic explanation](topic/README.md) and [local agent notes](topic/.agent/instructions.md).
- [Experiment record](experiment/README.md).
- [Integrated project](project/README.md).
- [Lab manifest](lab/lab.json).
- `atlas.html` is the actual shell for the generated knowledge map; edit it when changing atlas behavior.

Replace placeholders before registering a topic or lab. `scripts/lab.py` validates actual catalog records and registered manifests; template placeholders are not live entries.
